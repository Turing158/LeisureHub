## 这是什么？

如果你也觉得浏览器的主页不太够用，大概遇到过这些情况：

- 书签栏越堆越长，常用的那几个站总是埋在文件夹的第三层里；
- 想知道今天几号、出门要不要带伞，得分别去开日历和天气网站；
- 想把主页打扮成自己的样子，要么装个笨重的扩展，要么注册个云同步账号。

Leisure Hub 就是一张铺满整个屏幕的方格墙：空格子点一下就能加网站，格子之间按住拖动就能换位；也可以往格子里放日历、天气、搜索这样的小组件。它不注册账号、不连服务器，所有数据都保存在你浏览器的本地存储里。

> 简单说：**它是你的浏览器主页，不是又一个书签管理器。**

## 它能帮你做什么

| | 能力 | 说明 |
| :---: | --- | --- |
| 🧱 | **整屏方格墙** | 网格铺满一屏、从不滚动。方格边长由窗口宽高实时反推，任何窗口大小下都放得下。 |
| 🔗 | **网站方块** | 填个名称和网址就行。图标支持图片地址或 emoji，不填就用首字母生成一枚色块。 |
| 🧩 | **内置组件** | 日历、天气、搜索三种小组件直接搬进方格，同一个组件想放几个放几个。 |
| 🖐 | **拖拽整理** | 拖到空格是移动，拖到有内容的格子自动交换，松手有落位动画，拖出网格会自己弹回去。 |
| 📐 | **大小随你** | 每个方块可占 1×1 到 4×4 格（搜索框可以更宽），组件的版式会跟着占格大小自动切换。 |
| ↩️ | **误删可救** | 删除不弹确认框，底部出现一条 5 秒撤销提示，鼠标停在上面时倒计时会暂停。 |
| 🎨 | **随你打扮** | 纯色或网络壁纸背景（可加模糊）、磨砂开关、遮罩浓度、动效三档，都收在设置抽屉里。 |
| ♿ | **键盘友好** | Esc 关浮层、方向键走右键菜单、关闭后焦点自动归还，并尊重系统的「减少动态效果」与「降低透明度」设置。 |

## 内置组件

链接方块只负责跳转，组件则把小工具直接搬进方格。在添加对话框的「组件」tab 里点击即可放置，同一种可以放多个——比如一个百度框、一个知乎框，各搜各的。

| 组件 | 介绍说明 |
| --- | --- |
| 📅 **日历** | 1×1 只显示今天日期，放大后依次展开星期条、月视图、完整面板等十来种版式；跨过零点自动翻到新的一天。 |
| ⛅ **天气** | 数据来自 Open-Meteo，免费且无需注册。城市搜索、实时温度与逐小时 / 多日预报，最大版式还有风速湿度等指标。右键方块即可设置城市。 |
| 🔍 **搜索** | 在方格里直接搜。内置百度、Bing、Google、知乎，也能在设置里添加自定义引擎；支持搜索建议、内联补全和最近搜索，每一项都有独立的隐私开关（见下节）。 |

## 快速上手

**1. 启动**

本地预览用 `npm run dev`（见「给开发者」）；部署则把构建出的 `dist/` 目录丢到任意静态托管上，再把浏览器主页设过去即可。

**2. 放上你的第一批方块**

点击任意空方格，弹出添加对话框：**自定义**里填网址，**推荐**里一键加入内置条目，**组件**里挑日历 / 天气 / 搜索。

**3. 整理和打扮**

按住方块拖动换位；右键方块可以编辑、删除或刷新；右键页面空白处、或从屏幕边缘的手柄打开设置抽屉，换背景、调磨砂、改网格尺寸。

## 关于隐私，请留意几点

- 没有账号、没有后端、没有统计埋点。网格与设置都存在浏览器的 localStorage 里，换设备或清浏览器数据时不会自动跟随。
- **搜索建议与内联补全默认关闭**。这两项只能走 JSONP（主流引擎的建议接口都不发跨域头），而 JSONP 请求会带上对应域名的 Cookie，等于把「你正在打什么字」告诉搜索引擎——所以必须由你显式打开。
- 搜索记录只留在本地，随时可关、可清，不发给任何人。
- 天气请求发往 Open-Meteo 的公开接口，不带任何身份信息。
- 网址和背景图都只接受 http(s) 地址，`javascript:` 等协议一律拒收。
- 从旧版升级时，首次打开会把 `starfall-hub:*` 本地存储键迁移到 `leisure-hub:*`；迁移失败会保留旧键，方便回退。

## 一些贴心的小设计

- **版式跟着大小走**：日历和天气都按占格形状准备了成套版式，1×1 是极简一格，4×4 是完整面板，改尺寸时自动切换。
- **网格缩了不丢东西**：把网格调小时放不下的方块进入暂存区，调大后自动回到格子里。
- **刷新也不丢**：存储结构带版本号，读到不认识的字段逐项回退到默认值，而不是整份清空。
- **动画可以关**：系统开了「减少动态效果」时自动停用位移与缩放动画，功能不受影响。
- **旧浏览器也有底**：不支持磨砂滤镜的环境退化为纯色半透明遮罩，浮层照常可用。

## 运行环境

- 一款近两年的现代浏览器（Chrome / Edge / Firefox / Safari 均可）
- 无需安装任何东西：构建产物是纯静态文件，任意静态托管都能跑
- 天气组件需要能访问 Open-Meteo 的网络；不用它也完全不影响其它功能

## 给开发者

项目主体在 [leisure-hub](leisure-hub)：前端是 Vue 3 `<script setup>` + TypeScript，构建用 Vite，状态管理 Pinia，无 UI 组件库，样式全部是原生 CSS 变量；网格与设置的持久化各自封装了单一读写入口，带 schema 版本校验。规划与设计文档在 [plan](plan) 目录（不进版本库）。

```powershell
cd leisure-hub
npm install
npm run dev       # 本地开发服务器
npm run build     # 类型检查 + 产出 dist/
npm run preview   # 预览构建产物
```
